发布deb包

  1. 注册 Launchpad 账号

https://launchpad.net/

  1. 创建 GPG 密钥
gpg --full-generate-key

选择 RSA (默认) 和 4096 位长度

设置有效期（推荐选择 0 永不过期）

输入你的姓名、邮箱等信息

gpg --armor --export your-email@example.com > public-key.txt
sudo apt install ubuntu-dev-tools
