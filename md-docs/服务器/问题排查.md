
# 问题排查

查看当前目录下所有目录和文件磁盘占用前 10 名

```bash
du -sh * 2>/dev/null | sort -hr | head -10
```

只查看目录（不包含文件）

```bash
du -h --max-depth=1 2>/dev/null | sort -hr | head -10
```

```bash
sudo apt install ncdu
ncdu .
```
